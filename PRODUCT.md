# LilTeam Cloud

Thai website rental service at rent.lilteam.site. Customers preview the actual LilTeam storefront, choose an active package, create an account, fund their Cloud wallet, open a shop and renew it. Platform admins manage branding, packages, rental features/releases, users and payment review. The rental app has its own persistent JSON data and calls the main shop through its existing internal API.

The user requests a complete redesign of public and management pages, animated presentation and screenshots of the main shop's pages. Preserve real prices, authentication, balances, ownership, provisioning, renewal, CAPTCHA, receipt verification and private slip access. Do not invent testimonials or service statistics. Private backend showcase screenshots use a local demo dataset and must be labelled. Production publishing is authorized by the existing website work instructions.
